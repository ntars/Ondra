# ondra-memory · 记忆（合并版）

旧版把记忆拆成十几个包（抽取 / 去重 / 衰减 / 图谱 / 做梦 / 修复 / 向量 / 多模态…）。
新版**合并成一个**：它们读写同一份数据，拆开只会让「谁最后写」变成猜谜。

## 保留的四件事

| 能力 | 在哪 | 一句话 |
|---|---|---|
| 去重 | `service.ts#remember` | 同文不新建，只累加引用 |
| 关联 | `service.ts#link` | 双向存，读时取并集 |
| 衰减 | `service.ts#recall` | 按**最近被引用**算，不是写入时间 |
| 淘汰 | `service.ts#evictIfNeeded` | 超容量按最久没被引用出局 |

## 对外

`ctx.memory`：`remember(text, kind)` / `link(a,b)` / `recall(query)` / `all()`。

## 不做

- 不落盘：写盘由快照插件负责（一份状态，一个写入者）。
- 不抽取：把对话变成记忆点是模型的事，本插件只接收成品。
- 不做向量检索：关键词 + 一跳邻居在 5000 条以内足够；真需要再加，不预留空接口。

## 配置

`src/settings.ts` 的 `FIELD_SPECS` 是唯一真源（6 个字段），默认值不写第二份。
