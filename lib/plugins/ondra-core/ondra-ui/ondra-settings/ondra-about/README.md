# ondra-about · 关于空谷（合并后）

关于空谷现在有四段，**隐私与安全**与**问题反馈**都并入这里：边界与报障都属于
「这台机器上的这个应用」，和版本号同屏反而更容易找——报障时版本号就在上面。

| 段 | 内容 | 设置键 |
|---|---|---|
| 版本 | 版本号与阶段、检查更新、更新通道、当前人设包 | `about.channel` |
| 本机 | 清除缓存、系统权限、开源许可 | — |
| 隐私与安全 | 允许联网、允许读取屏幕、日志脱敏、崩溃上报、API Key 存放 | `privacy.*` |
| 问题反馈 | 问题类型、建议详情、附件、提交反馈 | — |

## 口径

- 隐私开关是**总闸**，不是提示：关掉联网后，插件也不该再访问网络——
  这条在运行时接通后由 `ondra-settings` 注入，界面这里只负责写入与显示。
- 提交反馈会带版本号与最近的系统日志，不带对话内容（文案里写明）。
