# ondra-settings · 设置面板容器

设置面板的骨架：左栏导航、右栏标题、滚动区。**5 个分类**，容器只负责把它们排进
导航并给统一版式——不分段、不加分割线，一条清单到底。

| 顺序 | 分类 | 子插件 | 内容 |
|---|---|---|---|
| 1 | 通用设置 | `ondra-general/` | 外观（主题 / 语言 / 字号）、权限、启动、通知、浏览（网页白名单入口） |
| 2 | 模型基座 | `ondra-models/` | 六类来源：官方 / 合作 / 免费 / 自定义 / 本地部署（llama.cpp 真起服务）/ 本地网关 |
| 3 | 通道接口 | `ondra-channels/` | QQ 机器人这类外部通道：开关、凭据、投递策略 |
| 4 | 人设设定 | `ondra-persona/` | 人设包、称呼、**对话**、**记忆与数据**、**语音与音色** |
| 5 | 关于空谷 | `ondra-about/` | 版本、更新通道、清除缓存、系统权限、**隐私与安全**、**问题反馈**、开源许可 |

## 合并原则

现在的五类对应「谁在管」，而不是「有多少个开关」：

- **对话偏好 / 记忆与数据 / 语音与音色 → 人设设定**：说话的方式、记住什么、什么声音，
  都是「这个人怎么样」，不是应用配置；
- **隐私与安全 / 问题反馈 → 关于空谷**：边界与报障都属于「这台机器上的这个应用」，
  和版本号同屏反而更容易找到（报障时版本号就在上面）；
- **插件的新增/卸载**不进设置，归 `ondra-plugins` 页。

被删掉的是分类，不是功能：每组内容都原样搬到了新位置，键名一个没改
（`dialog.*` / `memory.*` / `voice.*` / `privacy.*` 保持不变），所以运行时的映射不用动。

## 取值的来源

所有设置值由 `ui/settings_spec.dart`（键 / 标签 / 选项 / 默认值）与
`ui/settings_client.dart`（投影）持有，取值口径按官方 DeepSeek Harness 解包读到的字典对齐：

| 设置 | 官方出处 |
|---|---|
| 权限三档 | `dsh-client-ui-permission-presets` |
| 语言 | `dsh-client-locale` |
| 字号（仅会话内容） | `dsh-client-ui-theme` |
| 繁忙时的发送行为 | `dsh-client-ui-conversation` |
| 性能与用量（默认详细，显示在对话日志底部） | `dsh-client-ui-chat` |
| 模型基座 | `dsh-client-ui-settings-models` |
