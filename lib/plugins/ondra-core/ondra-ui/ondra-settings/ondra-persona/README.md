# ondra-persona · 人设（合并版）

旧版把 loading / vars / assemble / evolve 拆成四个包。新版一个：它们操作的是**同一个对象**——
当前身份，以及它渲染出的那一段提示词。

## 对外

`ctx.persona`：`install(packs)` / `switch(id)` / `active()` / `list()` / `segment()`。

## 三条口径

1. **切换 = 换段**：切包立即重渲染 `segment()`，中间不留「名字变了语气没变」的窗口。
2. **不读盘**：包解析在加载器里，服务只接收成品；一个状态一个写入者。
3. **关掉就空串**：`segment()` 返回空串而不是默认口吻——空段比错的人设更安全。

## 界面侧

设置 →「人设设定」页由同目录 `ui/` 提供（`persona_client.dart` 是投影）：
显示当前包、重载、导入、重置。界面不读包文件，只读投影。

## 设置界面：人设设定（合并后）

人设设定现在有五段，**对话 / 记忆与数据 / 语音与音色**都并入这里——它们回答的是
「这个人怎么说话、记什么、什么声音」，不是应用配置。

| 段 | 内容 | 设置键 |
|---|---|---|
| 人设包 | 当前人设、重载、导入、重置 | — |
| 称呼 | 让你怎么叫我 | — |
| 对话 | 繁忙时发送、回车发送、回复长度 | `dialog.*` |
| 记忆 | 允许记住 / 引用记忆 / 推断偏好；保留期 / 容量 / 自动归纳 | `dialog.remember` 等、`memory.*` |
| 数据 | 数据位置、导出全部数据、清空全部数据 | `data.location` |
| 语音 | 朗读、音色、语速、识别语言 | `voice.*` |

键名沿用原来的分类前缀（`dialog.*` / `memory.*` / `voice.*`），所以运行时侧的映射
不用跟着改；这次动的只是界面层级。
