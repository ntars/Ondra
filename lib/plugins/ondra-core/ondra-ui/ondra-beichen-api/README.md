# ondra-beichen-api · 合作 API

模型基座里的「合作 API」一类由这个插件提供。它**只回答一件事**：合作方的接口长什么样
（地址、密钥变量名、模型目录）。请求由内核发，密钥由平台层写钥匙串——这里既不实现
请求，也不存密钥。

## 换合作方

改两处之一：

1. Dart 侧（界面现在读的）：`ui/catalog.dart` 里的 `beichenPresets`——地址、密钥变量名、模型 id；
2. 运行时侧（Cordis 插件）：插件配置的 `label / baseUrl / apiKeyEnv / models`。

两边字段一一对应。**不要**把合作方的地址写进模型基座的代码里：那样换一家就要改界面。

## 为什么地址默认留空

合作方给的地址各不相同，写一个假的（`api.partner.example`）会让人以为它真能用。
地址为空时，添加预设会自动进编辑器，先补地址再保存。

## 契约

| 字段 | 含义 |
|---|---|
| `id` | 提供商 id（小写开头，可含数字与短横线） |
| `name` | 界面显示名 |
| `baseUrl` | 兼容 OpenAI 协议的地址（含 `/v1`） |
| `apiKeyEnv` | 没存密钥时回退的环境变量名 |
| `models[]` | 模型 id 列表 |

界面按 `ProviderCategory.partner` 归类，不判断具体是哪一家——所以这个插件可以
整包替换成任何合作方。
