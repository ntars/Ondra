# ondra-emotion · 情绪（合并版）

旧版把情绪拆成 core / diffuse / express / project / stage / breath / absence 近十个包。
新版**合并成一个**：它们共用一份状态。拆开之后「表情变了、正在输入还亮着」这种穿帮，
只能靠事件对时去补，而补不齐。

## 三件事，一份状态

| 能力 | 方法 | 口径 |
|---|---|---|
| 情绪 | `set(level, cause)` | 0–5 整数档；cause 只进日志，不进模型上下文 |
| 表现 | `express()` | 低于门槛不表现（subtle 起 / open 起） |
| 在场 | `presence(phase)` | 打字才亮「正在输入」；走神的长停顿一律熄灭 |

## 呼吸感

`breath()` 一天最多两次、同一动作一天最多一次；跨零点懒换日，不装定时器。

## 不做

不发送消息、不画界面、不给「长停顿也显示正在输入」留开关。
