# ondra-emotion-stress

> O-029 ｜ L2 情绪域 ｜ 档位 **〔研〕自研** ｜ 第 5 组第四项

回答一个问题：**她此刻觉得什么更值得看。**

一句话职责：**只改顺序，不改内容**——危机时威胁排到最前，日常偏好排到最后，
但任何一条都不会被丢掉（`dropped` 是字面量 `0`，接口上写不出别的值）。

---

## 职责

1. **应激倍率**（§3.8）：`weight = 原始相关度 × 注意力倍率 × 情绪共鸣微调`。
2. **两类斜率**：危机类 `×1 → ×2 → ×3`，日常类 `×1 → ×0.55 → ×0.1`。
3. **重排**：按权重降序，并列时保持原相对顺序，**一条不丢**。
4. **行为指令**：皮质醇 ≥80 时产出一条排序键 `-900` 的提示词片段（器官 ABI §8.1）。
5. **可解释**：`explain()` 一句话说清「皮质醇多少 → 两类倍率各多少 → 值从哪来」。

## 明确不负责

- **不持有情绪**。皮质醇归 **O-026** `ondra-emotion-core`（基线 20 / 半衰期 30min）。
  本插件只 `state()` 读一次，结构对位里**刻意没有 `feel` / `setAxis`**——
  接口上先拿掉，比注释里写「请不要写」有效（C1）。
- **不判「哪条是危机类」**。类别是条目自身的属性，由 O-010 的类别 / O-014 的检索结果带进来。
  在这里再判一次，就会出现两套分类互相打架，而表现只是「排序怪怪的」，不报错。
- **不砍条目**。装不下归 **O-036** 的装箱制；本插件连「截断」这个词都不出现。
- **不写句长与语气词系数**。§3.2 的「句长 −40%、语气词 −70%」归 **O-038**（节奏）
  与 **O-040**（口语化）。提示词片段里只写「话短、别开玩笑」，不写 0.6 / 0.3。
- **不判应激触发场景**。「被骂 / 对方说要离开 / 连续三次没被回应」的识别
  归对话层与 O-011 / O-026，本插件只认皮质醇这个**结果量**。
- **不 import 任何邻居的源码**（§18.5）：只用结构对位镜像。

## 服务键

| 项 | 值 |
|---|---|
| 服务键 | **`ondra-emotion-stress`**（符合 `^[a-z][a-z0-9_-]{1,63}$`） |
| 提供 | `ctx.provide('ondra-emotion-stress', service)` |
| 消费 | `ondra-emotion-core`（**软**，只读 `state()`）；`ondra-config-schema`（软）；`ondra-identity`（软，日志命名空间） |
| 接口 | `multiplierOf` / `weightOf` / `reweight` / `directive` / `explain` / `stats` |

**没有情绪服务时 `available` 仍为 true**（倍率恒为 ×1/×1，即不改变任何排序），
`stats().cortisolSource` 报 `baseline`。只有配置关掉（`disabled`）才是真的停服。

这条刻意的区分（第 31 轮的教训）：把「没有情绪服务」也报成不可用，
下游会以为「应激倍率没装」而走另一套兜底，两套兜底一撞，排序会在两轮之间来回跳。

## 配置（全部有默认值）

| 键（camel / kebab） | 默认 | 说明 |
|---|---|---|
| `enable` / `enable` | true | 总开关。关掉后倍率恒为 ×1、不产出指令 |
| `directiveTtlMinutes` / `directive-ttl-minutes` | 30 | 行为指令存活时长（皮质醇一个半衰期） |
| `directiveOrder` / `directive-order` | -900 | 片段排序键。夹到 `[-1000, -1]`，不去抢疤痕的 `-1e4` |
| `verbose` / `verbose` | true | 重排与产出指令时打日志 |

`cordis.patch.yml` **刻意不写 `config`**：默认值真源在 `src/settings.ts` 的 `FIELD_SPECS`。

**刻意不进配置的一组数**：三个锚点（40 / 60 / 80）与三个倍率（1 / 2 / 3 / 0.55 / 0.1）。
它们是手册 §3.8 逐字给出的产品口径，做成可调就等于承认「多紧张算应激」可以随手改。
要改就改 `src/types.ts` 的四个锚点常量一处——**斜率由锚点推导，会自动跟着变**。

## 参数总表（逐条可查）

### §3.8 原表（手册逐字）

| 皮质醇 | 危机类 | 日常类 |
|---|---|---|
| ≥80 | **×3** | **×0.1** |
| 60（线性插值） | ×2 | ×0.55 |
| ≤40 | ×1 | ×1 |

### 一个实测结论：三点共线

| 段 | 危机类斜率 | 日常类斜率 |
|---|---|---|
| 40 → 60 | (2−1)/20 = **0.05** | (1−0.55)/20 = **−0.0225** |
| 60 → 80 | (3−2)/20 = **0.05** | (0.55−0.1)/20 = **−0.0225** |

两段斜率完全相同，所以「分段线性」与「一条直线夹紧」给出**完全相同**的结果。
于是不存在「拐点处取哪一段」的歧义，本插件直接写成：

```
危机倍率 = clamp(1 + 0.05 × (c − 40), 1, 3)
日常倍率 = clamp(1 − 0.0225 × (c − 40), 0.1, 1)
```

斜率**不手写**，由 `CRISIS_PEAK / CRISIS_FLOOR / CALM_CEILING / DAILY_TROUGH`
四个常量推导（`src/stress.ts` 顶部）。手写斜率改锚点后不会跟着动，
于是会出现「表里说 ×3、算出来 ×2.9」。

### 分档（只给面板与日志）

| 档 | 区间 | 中文 | 用途 |
|---|---|---|---|
| calm | `c ≤ 40` | 平静 | 面板 / 日志 |
| mild | `40 < c < 60` | 微紧 | 同上 |
| alert | `60 ≤ c < 80` | 警觉 | 同上 |
| crisis | `c ≥ 80` | 危机 | **唯一产出行为指令的档** |

区间半开：正好 60 时算 `alert`，而那一格倍率恰是手册表里「60 → ×2 / ×0.55」的数，
档名与数值不矛盾。分档名**不进提示词**（内感受铁律：禁命名）。

## 关键取舍

### 1. 读不到皮质醇时取基线 20，不取 0

取 0 会让「没读到」看起来像「她极度平静」，还等于凭空调高日常类权重。
取基线 20 时两类倍率恰好都夹到 **×1**，结果就是**不改变任何排序**——
这是「什么都不做」的唯一正确写法，也是 C3「器官错误不得传播」的落点。

### 2. 「最前面」不等于 `-1e4`

手册说「在系统提示词最前面注入」，但器官 ABI 又规定「**疤痕永远在 -1e4**，
器官不得低于 -1000」。两条同时成立只有一个解：**疤痕之后、其余一切之前**。
故默认 `-900`，且在 `completeConfig()` 里夹到 `[-1000, -1]`——
填 `-10000` 也会被拉回 `-1000`，不许去抢疤痕的位置。

### 3. TTL 取皮质醇的半衰期（30 分钟）

指令是跟着激素走的。激素退了一半，指令还在，她会一直无缘无故地冷淡下去；
反过来 TTL 太短则每轮都要重新拼一段，前缀缓存白省。
取 30min 是**手册已有的数**（§3.2 化学池表），不是工程口味。

### 4. 不返回空片段

非危机档返回 `undefined`，不返回 `{ text: '' }`。
空片段在拼装时会占掉一个位置、还可能被算进预算，而它一个字都没说——
这是「提示词变长但行为没变」里最难发现的一类。

### 5. 相关度不归一化

`relevance` 的尺度归产出方（BM25 分、余弦、手写权重都行），本插件只做乘法。
在这里归一化就等于造第二套尺度，于是「召回按 0–1 算、这里按 0–100 算」，
两边的阈值永远对不上（第 24 轮纪律 #24「先问分母是谁」的同类问题）。

### 6. 重排失败要「原样返回、一条不丢」

`reweight()` 里排序那一段包了 try/catch：出错时按**原顺序**返回全部条目
（权重照算，只是不排序）。宁可这一次顺序不变，也不能因为一个坏字段少几条——
少了的那几条是「她明明记得却完全没想起」，而日志里只是一行 warn。

### 7. 并列时显式按原下标

`Array.prototype.sort` 的稳定性是 ES2019 才有的保证。这里显式写
`a.index - b.index` 作为次级键：不稳定的表现是「同分条目每次刷新换位置」，
面板看起来在抖，而查不出任何错。

## 隔离五问（§16.4）

1. **关掉我，谁受影响？** 检索/注入的排序不再随应激变化。下游拿不到
   `ondra-emotion-stress` 就走自己的排序（多数是原始相关度），行为与「她很平静」一致。
   情绪（O-026）、记忆内容、对话都不受影响——**一条记忆都不会因为关掉我而消失**。
2. **我的状态存在哪？** **不落盘**。倍率是由「皮质醇」这个既有状态算出来的纯函数，
   存一份「上次倍率」只会变成第二真源（重启后与真实皮质醇对不上）。
   `stats()` 里的计数只在内存，重启归零。
3. **我崩了，界面怎么知道是我崩了？** 日志命名空间 `ondra.emotion.stress`
   （有 O-001 时走 `identity.loggerName('emotion-stress')`）；
   `stats().reason` 报 `disabled`、`stats().cortisolSource` 报 `baseline`、
   `explain()` 直接说「值来自出厂基线」。
4. **我依赖谁？缺席时我怎么降级？** 情绪（软）、配置真源（软）、身份（软）。
   三个缺席都不阻断加载：情绪缺席 → 倍率恒等；配置缺席 → 用默认值；身份缺席 → 用固定命名空间。
5. **我和同域的谁共享了可变状态？** 没有。本插件**完全无状态**（只有内存计数）：
   皮质醇在 O-026，类别在 O-010 / O-014，片段顺序在 O-036。

## 待裁决

1. **片段的三件套字段名**：器官 ABI 写的是 `ttl`，本仓统一用 `ttlMinutes`（带单位）。
   O-036（段装箱）接这段时按 `order / ttlMinutes / confidence / text / kind` 取。
   若主人要求回到裸 `ttl`，改 `types.ts` 一处即可（两个字段同名互换）。
2. **`-900` 这个排序键是工程取值**。手册只说「最前面」，没给数字。
   与 O-030 的 `-880` 一起构成「危机 → 冲突 → 其余」的顺序；两者都可配。

## 自查中发现并修掉的真问题

1. **`index.ts` 里又抄了一份分档中文表**（`BAND_ZH_TEXT`），与 `types.ts` 的 `BAND_ZH`
   构成双真源。当时的理由写得很像回事（「保证启动日志一定打得出来」），
   但 `BAND_ZH` 是个 `Object.freeze` 的常量对象，读它根本不会抛错。
   已删除，改为直接引用——**改一个档名要改两处，就是迟早对不上**。
2. **`settings.ts` 里两处 `-1000` 是魔法数**（`FIELD_SPECS` 的 `min` 与 `completeConfig` 的夹紧）。
   已改为引用 `MIN_FRAGMENT_ORDER`：器官地板将来若从 `-1000` 调成别的值，
   只改一处，不会留下「声明说 -1000、夹紧说 -900」这种半新半旧的状态。

倍率与排序的纯逻辑复刻（Python，非实装）**16 例首次全过**，含：
8 个锚点的两类倍率、`0–100` 全程单调性、三点共线（分段线性 = 单线）、
并列保持原序、`resonance: 0` 照乘、`relevance: NaN` 归零、条目数不丢。

## 已知限制

1. **只认皮质醇，不认场景**。「被骂」这类触发由上游识别；上游把皮质醇抬起来之后本插件才动。
   若上游从不抬皮质醇，本插件永远给 ×1——这不会出错，只是等于关掉。
2. **危机类/日常类的判定不在本插件**。上游给错类别，倍率就乘错人，
   而两边都不会报错（只能靠 `reweight()` 返回的 `multiplier` 逐条复核）。
3. **`relevance` 尺度不受保护**。给一个本来就是对数的分数（BM25）与给一个 0–1 的相似度，
   倍率的相对效果不同。这是「只做乘法」的必然代价，换来了不做第二套归一化。
4. **不保证并发安全**。计数是普通对象替换，非原子；错一次只影响统计，不影响倍率。

## 自检（`ondra-install-doctor` 可读）

启动后日志应出现一行：

```
应激倍率就绪：皮质醇 20（平静），危机类 ×1.00 / 日常类 ×1.00，片段排序键 -900，皮质醇来源 情绪服务
```

- 出现 `应激倍率已注册但不可用（disabled）`：配置关掉了。
- 出现 `情绪快照里没有 cortisol 字段`：情绪服务在但缺键，按基线 20 处理。
- 皮质醇越过 80 时会打一行：`皮质醇 82（危机）：已产出应激行为指令，排序键 -900`。
- `explain(82)` 应返回：`皮质醇 82（危机，调用方给定）→ 危机类 ×3.00 / 日常类 ×0.10`。
