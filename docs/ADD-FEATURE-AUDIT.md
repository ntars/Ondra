## 一、两个参考 App 的"应备功能"指纹

两款都是 Electron 应用。从 `Info.plist` 的能力声明 + `app.asar` 关键字计数（命中次数）得到下表：

| 功能域 | WorkBuddy | DeepSeek Harness | 关键证据 |
| --- | --- | --- | --- |
| 权限中心（麦克风/相机/蓝牙/日历/通讯录） | 强 | 强 | WB `NSMicrophoneUsageDescription`、日历/通讯录权限范围；DSH `NSMicrophone`+`NSCamera`+`NSBluetooth`，`麦克风权限`×2 |
| 语音输入（语音→文字） | 有(speech ×218) | **强** | DSH `语音输入`×14、`whisper`×47、`speech`×1249、"transcribe speech into message drafts" |
| 自定义模型 / 模型提供商 / 本地模型 | 有(custom model ×53) | **强** | DSH `自定义模型`×6、`模型提供商`×6、`ollama`、`vllm`、`本地模型`×1、`API Key`×86 |
| 备份 / 恢复 / 迁移 | **强**(backup ×404) | 有(backup ×94) | DSH `备份与恢复`×1、`导出数据`×1、`导入数据`×1、`数据迁移`×1 |
| 记忆 / 长期记忆 | 有 | **强** | DSH `memory`×3383、`长期记忆`×2、`第三方记忆 MCP` |
| 知识库 | **强**(知识库 ×144) | 弱 | WB 大量 "知识库" 用户侧管理 |
| 工作区 / 多会话 | 弱 | **强**(工作区 ×350) | DSH 多工作区 |
| 快捷键 | 有(hotkey ×68) | 有(快捷键 ×88) | 两者皆有总表 |
| 深色模式 / 主题 | **极强**(theme ×6977) | 有(深色模式 ×4) | 两者皆支持 |
| 通知 | 有(通知 ×50) | **强**(通知 ×263) | 两者皆有 |
| 插件市场 | 弱 | 有(插件市场 ×31) | DSH 有发现/市场 |
| 自动更新 | 有(Squirrel) | 有(app-update.yml) | DSH 明确 `自动更新`×3 |
| 深度链接 | 有(`workbuddy://`) | 有(`dsh://` ×8) | 两款都有协议处理器 |
| 隐私 / 离线 / 端到端 | 部分 | 有(离线 ×16, 端到端 ×4) | DSH 强调本地/离线 |

**关键校正**：用户说的"时间机器同款备份"，在两款 App 里**都不存在字面「时间机器」**（`时间机器` 命中 0/0）。它对应的是 DSH 的 `备份与恢复 / 导出数据 / 导入数据 / 数据迁移` 与 WB 厚重的 `backup`——即**版本化/可回滚/易恢复的备份**，不是 macOS Time Machine 本体。空谷应朝这个语义做，而不是去调用 Time Machine。

## 二、空谷现状基线（已实现，避免重复造轮子）

确认空谷**已经有**、常被误以为缺失的能力：

- **单窗单会话 + 三层进程**（壳 / Cordis 宿主 / dsh 内核），78 包 / 619 配置字段（可直接改 609）。
- **推理来源切换**：在线接口 / 本地大模型 / 免费模型三选一（内核 `model.list/select/configure/complete`）。
- **深色模式 + 跟随系统**（外观页：主题、字号、语言）。
- **快捷键总表**（`ShortcutSheet`，非阻断式查阅）。
- **通知页**（系统通知开关 + 静音/作息约束说明）。
- **声音页**：提示音、音量、**朗读（TTS 输出）**——注意这是**输出**，不是输入。
- **对话页 · 默认权限**：AI 的**能力范围**档位（只在对话内 / 限于工作区 / 不限制），属"agent 能力边界"类权限。
- **数据页**：会话 JSON / Markdown 导出、全部导出、**从文件恢复**（恢复时归档当前段）。
- **内置白名单浏览器**（关于页「打开下载页」实测弹出 `空谷 Ondra · 浏览` 980×700，真实加载 github.com/ntars/Ondra）。
- **记忆系统**（205 字段）+ **世界书**（背景知识插件）。

## 三、功能缺口清单（对照 WB / DSH）

| # | 功能 | 空谷现状 | 缺口等级 | 建议 |
| --- | --- | --- | --- | --- |
| G1 | **权限设置（应用级）** | 仅有"AI 能力范围"档位；无麦克风/相机/文件/日历/通讯录等系统权限的开关与授权说明 | **高** | 新增「权限」设置页：逐项列出本应用需要的系统能力（麦克风—语音输入、本地文件读写为记忆/世界书、网络—白名单浏览器），给出授权状态与"为何需要"。与现有"默认权限"分开，前者是"App 能碰什么"，后者是"AI 能碰什么"。 |
| G2 | **语音输入** | 声音页只有 TTS 输出，无任何麦克风→文字入口 | **高** | 输入框加麦克风按钮（或全局快捷键），接入本地 Whisper（参考 DSH `whisper-1`）做离线听写，转写进草稿；首次使用时引导授权（DSH 有"使用语音输入前需要安装/打开语音输入引导"）。 |
| G3 | **自定义模型** | 仅三档预设源切换，无"添加自定义端点 / 填 API Key / 选 Ollama·vLLM / 调基址与模型名"的 UI | **高** | 对话页或插件参数下加「模型提供商」：支持 OpenAI 兼容基址、Ollama、vLLM、自定义；每项独立 API Key 保管（机密字段）。DSH 已验证此路径可行。 |
| G4 | **时间机器同款备份** | 数据页仅"会话导出/导入"，手动、单文件、无版本历史、无回滚 | **高** | 新增「备份与恢复」：定时/手动快照（整库：会话+记忆+世界书+配置），保留多版本，一键回滚；可导出迁移包（对应 DSH `数据迁移`）。README 当前写"备份由使用者手动完成"——此项直接改写该设计取舍。 |
| G5 | **知识库（用户可管理）** | 有"世界书"插件但无面向用户的建库/检索/编辑界面 | 中 | 把世界书升级为可见可编辑的"知识库"页：增删条目、分类、导入文档摘要，对标 WB `知识库`×144。 |
| G6 | **插件市场 / 发现** | 78 包内置，无外部发现、安装、更新通道 | 中 | 加"插件市场"：浏览、安装、启停、版本；DSH `插件市场`×31 为参照。注意本地优先取向，市场可走"可信清单"而非任意远程。 |
| G7 | **自动更新** | 关于页明确"无内置更新通道，需下载安装包覆盖" | 中 | 接入更新通道（Squirrel 式），后台检测、可选静默/手动，覆盖安装时保留配置与对话。 |
| G8 | **深度链接** | 无自定义协议处理器 | 低 | 注册 `ondra://`：从外部唤起（如浏览器插件、分享）打开特定会话/记忆/设置页。WB `workbuddy://`、DSH `dsh://` 均为先例。 |
| G9 | **工作区 / 多会话** | 设计上单窗单会话（README 明确"不做多用户与账号体系"） | **设计排除** | 不建议盲目加。若要做，先确认是否违背"陪伴体单关系"定位；可改为"多人格/多情境档"而非多账号。 |
| G10 | **隐私 / 离线 / E2E** | 本地优先、数据留本机（已有立场） | 低 | 补"隐私中心"说明页：明确数据落盘位置、是否出网、离线可用性；对标 DSH `离线`×16 / `端到端`×4。 |

> 用户点名的 5 项全部命中：**权限设置→G1 / 语音输入→G2 / 自定义模型→G3 / 时间机器同款备份→G4 / 以及其他→G5–G10**。

## 五、UI / 交互 / 细节体检（实机取证 10 处）

### 5.1 主界面
- **右侧栏"此刻 / 尚无读数"贴右缘、竖排、几乎无留白**，且中段有一条样式不一致的横线标记，含义不明、交互入口不明显。
- **左侧栏图标无文字标签**，首次使用只能靠猜（hover 提示在静态图里不可见）。
- 空状态中部大片留白，输入框偏下——属正常，但"今天 第 1 天"计数含义无说明。

### 5.2 设置面板（共性）
- **模态遮罩偏透**：背后主界面文字（"此…""每…实…数…"）透过遮罩成碎片，显杂乱。
- **面板左/右缘贴窗口边框**，左侧导航压住背后图标，拥挤。
- **左侧导航底部齿轮被窗口底边裁切**（贴边）。
- 选中项仅靠浅灰底 + 右侧小圆点，层级不够强（多处复现）。
- 说明卡片与可点选项样式接近，易混淆（对话页尤甚）。

### 5.3 各页具体问题
- **外观**：底部"大 18px"贴面板底边，留白极小；关闭 × 偏小。
- **声音**：确认**无语音输入**；提示音关闭时三项触发卡占大块禁用灰显，信息密度低；音量值"60"与"音量"标签未同行对齐。
- **通知**：分组标题"系统通知"与选项名"系统通知"同名同层级，区分弱；说明卡有**异常空格**（`那一句 搬到`、`不会弹——你回来` 破折号前后空格不一致）；无 hover/焦点可见态。
- **对话**：**默认权限"不限制 / 能读到整台机器"被默认选中且无红色警告/二次确认**——安全隐患提示不足；底部说明文字被裁切、无滚动提示；`ui` 状态显示 `permission: "full"` 与默认选中一致，需评估是否应改为更保守的默认值。
- **数据**：属"会话导出/导入"，**非全量备份**（印证 G4）；导入按钮"从文件恢复..."用半角 `...` 与 macOS `…` 不一致；"恢复会归档当前段"的副作用说明偏弱、无强调。
- **插件参数**：**619 字段无搜索/过滤**，仅 场景/模块/原始 三标签，定位极难；滑块与快捷按钮（一个月/三个月…）关系不明；"撤销"孤立在底栏；"1 段来源未登记"警告样式与统计文字一致，易被忽略。
- **关于**：仓库链接 `github.com/ntars/Ondra` 仅加粗文本，无外链样式/图标，不易识别可点；AGPL 全文无入口；更新提示框与按钮归属关系弱。

### 5.4 侧写（Inspector）
- 以浮层覆盖会话区右侧，**盖住输入框右下（模型选择「DeepSeek V4.1 Flash」被裁）**。
- 右侧"此刻/尚未读数"竖排文字与面板分离、归属模糊；浮层无投影/边界，层次弱。

### 5.5 内置浏览器（白名单）
- 实测能加载 GitHub Releases，**白名单拦截生效路径未见提示**。
- 标题栏下黑色地址条**不显示当前 URL**；**无前进/后退/刷新/停止**等导航控件；右上两人形图标功能不明。

### 5.6 高优先级 UI 修复建议（独立于功能新增）
- U1：收紧模态遮罩不透明度，杜绝背后文字透出。
- U2：右侧栏"此刻/读数"重做——给图例、增加留白、把那条异常横线说清楚或去掉。
- U3：左侧栏加常驻/悬停文字标签。
- U4：对话页默认权限改保守默认（如"限于工作区"），并对"不限制"加确认与醒目警告。
- U5：插件参数页加搜索框 + 字段分组折叠。
- U6：通知/关于页清理文案异常空格、统一省略号为 `…`、仓库链接做外链样式。
- U7：浏览器地址条显示 URL + 补导航控件 + 拦截时给明确提示。

## 六、下一步建议

1. **先确认范围**：P0 四项（G1–G4）是否本周期就做？其中 G4（备份）会改写 README 里"备份由使用者手动完成"的既有设计取舍，需你拍板。
2. **G9 工作区**建议保持"设计排除"，若要扩展用"多情境档"替代，避免偏离"单关系陪伴体"定位。
3. UI 体检的 U1–U7 多为低风险打磨，可随任一功能页改动时顺手修，不必单独立项。
4. 若开工，建议按 `Feature → 设置页/入口 → 数据目录落盘 → 自检网（check:ui/acceptance/contrast）` 的顺序，沿用现有三张自检网守住回归。
