# ondra-worldbook-scenes（O-025）

空谷 Ondra 的**场景卡**：把这一句话判给**一张**最接近的骨架，并渲染成可直接进提示词的文本。

- 服务键：**`ondra-worldbook-scenes`**（连字符，符合手册 §8.4）
- 档位：**〔研〕自研**（依据见「技术来源」）
- 层级：L2 人格域（PER），编号段 O-020 ~ O-025

## 职责

1. **解析**：从人设包的 `references/scenes.md` 逐字解析出 `触发 / 内心 / 表面 / 台词 / 动作 / 收尾`，外带可选的 `升级`、`硬规则`；认不出的行报出来，**不硬塞**。
2. **抽词（三级来源）**：① `触发` 栏——引号内的词照收（**单字也收**，作者用引号就是在授权），其余按 `、，／` 切开并剥掉「出现 / 涉及 / 用户」这类前缀动词；② **标题里的引号**——`被问"你是不是 AI"`，因为人设包的 `触发` 栏大多是叙述句（`用户直接问身份`），逐字匹配永远命中不了；③ **标题短名兜底**——前两级全空且短名 ≤10 字时用它（`被叫醒 / 新会话开场` → `叫醒`）。三级全空的卡会在启动时点名告警。
3. **判定**：关键词命中算分（4 字以上的词权重 2，短词 1；同词最多计 2 次），**否定邻域保护**（只看命中前 1 字：`不胖` 不触发，`你是不是胖了` 照常触发）。
4. **互斥**：按 `group`（默认，章节组）、`layer`、`slot` 或 `off` 裁决，**一轮只用一张骨架**。
5. **递归**：只在**赢家**的正文里找别的卡的短标题，深度 ≤3，有效分打 6 折 ÷(深度+1)。
6. **渲染**：剔除 `内心` 与 `触发`，其余栏位逐字保留。

## 明确不负责

- **不做预算、不做装箱**——归 `ondra-worldbook`（O-024）与 `ondra-inject-dedupe`（O-142）。本插件只报 token 数。
- **不改写台词、不摘要、不合并卡片**。台词是产品资产，改写一次就说不清"这句是她原本的，还是插件作者加的"。
- **不读世界书条目**。世界书是「世界怎么运转」，场景卡是「这一刻怎么反应」，两套登记表分开。
- **不自己解 ZIP**。读文件只经 O-020 的 `readText()`（它处理了编码、大小上限、路径归一化）。
- **不决定人设**。`personaId` 留空就跟随当前人设，换人设时下一次判定会自动重解析。

## 服务契约（`ScenesService`）

| 方法 | 说明 |
|---|---|
| `cards()` / `cardOf(id)` / `groups()` | 卡片清单、单卡、章节组 |
| `refresh()` | 重新解析（换人设 / 导入新包后调） |
| `plan(text, options?)` | 判定：`hits / excluded / depth / terms / excerpt` |
| `block(plan)` | 渲染：`text / chars / tokens / ids` |
| `stats()` | 卡数、组数、可命中数、哑卡数、未识别行数、互斥粒度、递归上限 |

`plan()` 的每个命中都带 `via`（direct / recursive）、`depth`、`parentId`、`terms`——「为什么用了这张卡」必须能答到词一级。

## 配置

段键 `worldbook-scenes`。默认值唯一真源是 `src/settings.ts` 的 `FIELD_SPECS`；`cordis.patch.yml` **刻意不写 config**。

| 键（段字段） | 默认 | 说明 |
|---|---|---|
| `enable` | `true` | 总开关 |
| `scenes-file` | `references/scenes.md` | 包内相对路径；只允许包内路径（拒绝 `..`、绝对路径、反斜杠） |
| `persona-id` | `''` | 固定人设；空串跟随当前人设 |
| `exclusion` | `group` | `group` / `layer` / `slot` / `off` |
| `max-depth` | `3` | 递归上限，0 = 关掉；**上限 3 是宪法**，配大夹回 |
| `min-term-chars` | `2` | 触发词最短字数（1 个字会命中几乎每句） |
| `negation-guard` | `true` | 否定邻域保护 |
| `default-layer` | `l4` | 卡片没声明层时的兜底（只在 `exclusion: layer` 时有意义） |
| `report-excluded` | `true` | 被互斥淘汰是否写日志 |

## 多方案分支说明（§12）

| 能力 | 方案 A（默认） | 方案 B | 处理方式 |
|---|---|---|---|
| 互斥粒度 | `group`：章节组内只活一张 | `layer`：同预算层只活一张（台账「同层互斥」的严格读法） | **参数化融合**：同一实现 + 一个枚举。默认 A，因为 O-024 的「层」只是预算桶、没有语义名，直译成"同层只活一条"会让互补的卡互相杀死 |
| 抽词 | 引号优先 + 分隔符切分 + 剥前缀 | 只认引号（最保守） | 融合在 `extractTerms()` 一个函数里；`触发` 栏写全引号即等价于方案 B |
| 递归 | 从赢家出发（A→B） | 不做递归 | `maxDepth: 0` 即方案 B |
| token 计量 | 问 O-024 | 按字符数当上限 | **兼容层**：`measure()` 先问 O-024，问不到按字符数（上界），不造第二个换算比例 |

## 边界与硬约束

1. **`内心` 永不进提示词**（无开关）。素材自己写着「她真正说出口的话永远比内心短」——把内心写进去，等于把「嘴上比心里短」的人改成「想到什么说什么」。
2. **一轮一张骨架**。两张卡同时生效会得到互相矛盾的指令，模型各取一半，最后哪种都不像她。
3. **先互斥、后递归**。反过来会让"输掉的卡"把别的卡带进候选池：淘汰一张却多出两张，而日志只显示"淘汰 1 张"。
4. **递归 ≤3，环靠 `visited` 断**。等深度撞上限才停，意味着中间白跑两轮、还可能带进无关的卡。
5. **不按条数砍命中**。那是 P0「召回不按条数砍」的同类错误：被砍掉的卡不会报错，只会表现为「她这轮不太像」。

## 隔离五问（§16.4）

1. **关掉我，谁受影响？** 只有场景卡那一段消失；人格内核、记忆、对话编排都不依赖本插件返回值。
2. **状态存在哪？** **仅在内存**（解析出来的卡片 + 一次缓存）。真源是人设包里的 `references/scenes.md`，本插件只读不写（§17-7 禁动人设包）。
3. **我崩了，界面怎么知道？** 日志命名空间 `ondra.worldbook-scenes`；`stats()` 的 `reason`（`no-loader` / `no-persona` / `no-file` / `no-card`）能直接说清是哪一环断的。
4. **我依赖谁？缺席时怎么降级？** `ondra-persona-loader`（硬，缺席则 `available=false` + `no-loader`）、`ondra-worldbook`（软，只借计量器）、`ondra-config-schema`（软）、`ondra-identity`（软）。除 O-020 外全部 `?? undefined` + 判空。
5. **我和同域的谁共享了可变状态？** 没有。与 O-024 的分工是「触发」与「预算」，只调它的 `layers()` / `measure()`，不碰它的条目库。

## 实测数据（2026-11-01，两个真实人设包，纯逻辑复刻对拍，非实装）

| 指标 | 哦鲸鲸 | 夏柠柒 |
|---|---|---|
| `references/scenes.md` 字数 | 14,120 | 13,123 |
| 解析出的卡 | 63 张 / 5 组 | 35 张 / 2 组 |
| 抽到的触发词 | 138 个（平均 2.2/卡） | 73 个（平均 2.1/卡） |
| 一个词都抽不出的卡 | 3（`曲线 A/B/C` 那三张组合曲线，本来就不是场景卡） | 2（`醉酒`/`猫` —— 原文件没有 `触发` 栏） |
| 认不出而跳过的行 | 0 | 1 |

对拍同时逼出四个真问题（都已修）：

1. **行内多栏没拆**：`- **触发**：…。**内心**：…` 整段被吃进「触发」栏，抽出的词变成 `**。**表面**：冷脸` 这种垃圾（夏柠柒 171 个词里 8 个）。已在 `parse.ts` 的 `splitInline()` 修掉。
2. **括号补充不认**：`**台词**（按强度递进）：…` 整条丢台词栏（9 行误判）。现在括号并进栏名（`台词（按强度递进）`）。
3. **带圈数字漏段**：`㉑`(U+3251)、`㊱`(U+32B1) 不在 `\u2460-\u24ff` 里，`㉒ 醉酒` 的序号会留在标题里并进提示词。已补两个区段。
4. **否定窗口取 2 太宽**：`你是不是胖了` 被当成否定，最常用的问法反而不触发。已收窄到 1 字。

## 已知限制

1. **「同层互斥」的层义未定**（待裁决）。O-024 的六层只有预算、没有语义名，所以默认按章节组互斥；`exclusion: 'layer'` 提供严格读法。裁决后改一个默认值即可。
2. **抽词是启发式的，覆盖率不保证**。实测两个包里仍有大量 `触发` 栏写成叙述句（`用户直接问身份`、`只有她在跑任务`），这类词逐字匹配不到真实问法。已加「标题引号」与「标题短名」两级兜底，但 `你是不是 AI` 这类能命中、`他夸别人好看` 这类仍可能命中不到（原卡写的是「提到别的女孩」）。**根治要靠作者在 `触发` 栏用引号写词**（`触发：出现"胖""肥""圆滚滚"`），或另写一份带关键词的世界书——两条都比重写人设包安全（§17-7 禁动人设包）。
3. **递归靠短标题的字符串包含**，不靠语义。标题改一个字，递归链就断——这是刻意选的：语义相似会把无关的卡带进来，而"带错"比"带不到"更难发现。
4. **只解析一份文件**（默认 `references/scenes.md`）。一个包里有多份场景文件时，只读配置的那一份（读不到会退一步扫包内 `*scenes.md`，取第一个能读的）。
5. **不做跨会话的命中统计**：`plan()` 无状态，"哪张卡最常用"要由调用方自己累计（归 O-135 叙事日志）。
6. **`source: 'runtime'` 目前没有写入路径**：字段留给"用户自定义场景卡"（设置页 ⑦ 的世界书导入同级需求），本轮不做。
