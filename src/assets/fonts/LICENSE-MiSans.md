## 子集化说明

为控制安装包体积，本项目对官方 `MiSansVF.ttf` 做了字符子集化，仅保留界面实际需要的字符范围：

| 范围 | 内容 |
| --- | --- |
| `U+0020-007E` | 基本拉丁字母、数字、ASCII 标点 |
| `U+00A0-00FF` | 拉丁补充（重音字母、货币符号） |
| `U+0100-017F` | 拉丁扩展 A |
| `U+2000-206F` | 常用标点（含中文全角标点、省略号、破折号） |
| `U+2190-21FF` | 箭头 |
| `U+2460-24FF` | 带圈数字 |
| `U+25A0-25FF` | 几何图形（界面指示符） |
| `U+2600-27BF` | 杂项符号与装饰符号 |
| `U+3000-303F` | CJK 标点 |
| `U+4E00-9FFF` | CJK 统一汉字（常用区） |
| `U+FF00-FFEF` | 全角字符 |

子集化不改变字形轮廓、字重轴与 OpenType 特性，视觉表现与官方字体一致。生僻字（CJK 扩展 B 及以后）不在子集内，如后续需要可在同一流程中扩展字符范围后重新生成。
